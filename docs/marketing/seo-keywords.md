# SEO target keywords

Compiled 2026-08-20 while planning how to accelerate audience beyond Product Hunt
and Facebook groups (tracked in #93). The site is brand new
(`eduparty.online`), so generic terms like "online games" or "english games" are
unwinnable — everything here is long-tail, low-competition, and matches what an
ESL/EFL teacher would actually type with a concrete problem in mind, not a
category browse.

## How to use this list

- Each primary term above should map to real, crawlable page content (not just
  landing-page copy) — see #149 for the content-pages issue.
- Check Google Search Console's Performance report periodically for which of
  these terms actually get impressions once pages are live; promote whichever
  ones show real query volume, drop the rest. Record findings back on #150 or
  update this file directly.
- Re-derive this list rather than trusting it blindly after a few months —
  actual search behavior from the pages going live will be better signal than
  this initial guess.
